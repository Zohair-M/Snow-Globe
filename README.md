# ❄️ Digital Snow Globe

An interactive, browser-based digital snow globe featuring ambient sound effects, a customizable blizzard wind speed slider, and mobile gyroscope support. 

---

## Features

- **Interactive Shaking:** Click or tap the globe on desktop
- **Wind Speed Control:** Adjust the falling snow speed dynamically with the wind speed slider.
- **Ambient Audio:** Features a cozy background track and a chime sound effect that triggers upon shaking.
- **Accessibility Toggle:** Easily mute or unmute the audio with the top-right button.
- **Alternative Theme:** Double-click the globe to transition from a cool winter night to a warm twilight sunset.

---

## Built With

- **HTML5 & CSS3** (Custom glass-style reflection styling, responsive layout, and keyframe shake animations)
- **Vanilla JavaScript** (ES6+, DOM manipulation, and DeviceMotion API integrations)
- **[tsParticles](https://particles.js.org/)** (For rendering the snow particle simulation)
